**BNB Hackathon Track 2** — CoinMarketCap-powered quant strategy skills with backtests, CMC MCP integration, and BSC testnet attestation.

All application code is in [`skill-reputation/`](skill-reputation/). **Start there.**

```bash
cd skill-reputation
npm install && cp skill/.env.example skill/.env
npm run strategy:all && npm run replay && npm run attest
```
