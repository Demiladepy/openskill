# Optional demos

These folders are **not part of the judge demo path**. The core flow is `npm run strategy:all` → `replay` → `attest` → `export:skills` in the repo root.

| Folder | Purpose |
|--------|---------|
| `demo-ui/` | Next.js dashboard shell (optional local UI) |

To run the demo UI:

```bash
cd demos/demo-ui && npm install && npm run dev
```
